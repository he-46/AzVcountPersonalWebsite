# 项目经历管理功能记录（2026-09-26）

## 变更

- 在后台“简历管理”页新增项目经历管理区域，可查看全部项目（含未公开项目）。
- 支持新增、编辑、排序、设置公开或隐藏、删除；删除前明确提示无法撤销。
- 复用现有 `/api/admin/portfolio` 接口，新增前端更新和删除调用。公开 `/about` 页只展示 `APPROVED` 项目，不需重启后端即可读取修改结果。
- 更新功能实现教程，避免沿用“没有管理页面”的旧描述。

## 使用与边界

登录后台，打开“简历管理”，在“项目经历管理”中填写项目名称、简介、技术栈、链接、排序数字及展示状态。修改现有项目时点击“编辑”；如不想公开，可改为“隐藏”，不必删除。排序数字越小越靠前。

项目链接须是 `http://` 或 `https://`，名称不超过 120 字，简介不超过 500 字，技术栈和链接不超过 255 字。前端做表单校验；现有后端接口目前仍是直接绑定 `Portfolio` 实体，尚未提供统一的服务端字段校验和更细粒度权限。公开页顶部个人介绍、技能标签、联系方式仍写在 `About.vue`，不受项目经历表单影响。

## 验证

- 前端生产构建通过（Vite 8.2.2）。
- 未连接线上数据库进行真实增删改验收；上线后建议先用测试项目走一遍“新增 → 隐藏 → 公开 → 编辑 → 删除”，确认数据和公开页符合预期。
